# Muse 自营商品页

自营规格名称或所属商品名称含独立单词 Muse / MuseAI 时，前台使用 Muse 展示页，目录链接指向 `/product/muse`。原来的 `/product/custom-…` 链接仍可使用。其他自营商品继续使用通用详情页。

页面展示蓝色视觉、真实规格与价格、交付摘要、购买须知、通用交付说明、三步交付流程和常见问题。手机端改为单栏，并保留底部购买入口。购买须知及交付说明从后台规格字段读取，不包含具体账号或接码链接。具体账号资料仍受原订单权限保护。

阅读确认绑定规格编号、版本、价格及说明内容。切换规格或后台修改这些内容后，需要重新确认。已在详情页确认说明时，下单弹窗直接进入邮箱步骤。

商家已确认 Muse 库存提供账号邮箱和接码链接，并提供交付后 5 天内首次登录问题售后。商品说明应说明领取位置、验证码的获取方式、首次登录的环境要求和售后材料；不要承诺永久可用、零封禁或本站自动接码，除非相应能力已实际验证。

页面更新不会修改旧订单的交付快照，也不会自动恢复商品展示或开放销售。付款渠道启用与验收独立进行。

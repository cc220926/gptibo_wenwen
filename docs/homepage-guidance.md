## 页面变化

- 主页增加一个可切换的购买引导区，每次只显示开通演示、选购帮助、售后案例中的一项。页签支持方向键、Home 和 End。
- 开通演示直接复用现有 `RechargeGuide` 六步教程，仅在弹窗打开时挂载；教程及其内嵌示意页面均未修改。主页概览明确以 ChatGPT 为例，其他商品仍以自己的交付说明为准。
- 选购帮助提供八条中英文问题，支持本地搜索、清空、空结果提示及答案展开。不会提交搜索内容。订单、客服按钮使用既有入口。
- 售后区明确标注为“处理流程示例，并非真实客户案例”。没有虚构客户评价、交易记录或到账承诺。
- 侧栏分类移到商品区顶部。桌面三列、中等宽度两列、手机单列；保留全部真实商品、排序、配置价格、上下架规则及详情页地址。空筛选可恢复全部商品。
- 店铺自定义品牌、标题、说明继续使用原配置。

## 履约保护边界

没有修改后端、数据库迁移、支付、充值、库存交付、人工履约、售后处理接口、订单 Hook 或公共业务模型。商品详情页、下单窗口和邮件找回原实现未修改。

`src/App.tsx` 仅新增展示组件及其样式的导入，并修改 `page === 'store'` 对应的主页 JSX。为防止“看起来没改”代替证据，增加了可运行的范围检查：

```sh
node scripts/verify-homepage-scope.mjs d7df5ef63ba99577048baf2ab28512ee4d51c2df
```

该命令检查文件白名单，以 TypeScript AST 对比主页分支之外的整个 App，并对比商品目录返回 JSX 之前的全部计算。它不能替代业务测试或真实渠道验收。

## 本次本地预览

验收使用 `artifacts/homepage-guidance/vite.config.ts` 读取主站公开商品目录的本地快照，按主站的规格、价格及 `hiddenProductIds` 渲染，不自行添加示例商品，也不把分站限制套用到主站。快照仅保存于被 Git 忽略的验收目录，不随源码提交。桌面商品网格会根据实际卡片数自适应，最多三列；主站当前四类商品使用两行两列，避免三加一的空缺布局。

预览服务仅监听 `127.0.0.1:5179`。交易请求统一拒绝，不连接真实支付、供应商或生产数据库；预览不会改动主站的商品、权限或履约配置。截图、原始测试日志、范围审计和验收矩阵保存在同目录；`artifacts/` 被 Git 忽略，临时验收材料不随源码提交。

当前机器可重新运行：

```sh
npm run build
npx vite preview --config artifacts/homepage-guidance/vite.config.ts --host 127.0.0.1 --port 5179 --strictPort
```

价格为获取快照时的主站公开价格，不会自动同步后续变动。其他开发环境请按项目 README 配置本地后端。现有教程的内嵌示意页面在 Vite 热更新模式会遇到 React preamble 错误，因此教程画面须使用构建后的本地 preview 验收；本次没有为此修改既有教程。
